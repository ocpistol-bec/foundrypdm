Bundled fonts for the web portal
================================

Atkinson Hyperlegible Next and Atkinson Hyperlegible Mono
Designers (from the upstream METADATA.pb): Braille Institute, Applied Design Works, Elliott Scott,
Megan Eiswerth, Letters From Sweden.
License: SIL Open Font License 1.1. The full text, with its copyright line, is in OFL.txt beside
each family. Neither OFL.txt declares a Reserved Font Name.

Source: https://github.com/google/fonts at commit 5026800714d07231937d92eb4cceabf06e05d74e,
directories ofl/atkinsonhyperlegiblenext and ofl/atkinsonhyperlegiblemono (upstream projects:
https://github.com/googlefonts/atkinson-hyperlegible-next and
https://github.com/googlefonts/atkinson-hyperlegible-next-mono).

The files are copied unmodified (variable fonts, weight axis 200 to 800). Only the file names
changed: "[wght]" became "-VariableFont_wght", so the names need no URL escaping.
